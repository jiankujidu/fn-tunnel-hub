使用教程（v2.1.2）

第一步 · 打开面板

安装完成后，飞牛桌面点「穿透管家」图标，或在浏览器打开 http://NAS_IP:19999（自定义端口则在向导里设置）。面板三个页签：运行状态 / 设置 / 教程。

第二步 · 设置各引擎（Token 填这里）

到「设置」页，勾选要启用的引擎开关，填入对应 Token，点「保存配置并重启引擎」即生效。Token 保存后回显自动打码，不会明文泄露。四个引擎的凭据获取方法如下：

① Cloudflare Tunnel（推荐：外网直接访问，可绑自己域名）

  1. 注册 Cloudflare 并把域名托管进去：https://dash.cloudflare.com/
  2. 进入 Zero Trust：https://one.dash.cloudflare.com/ → Networks → Tunnels → Create a tunnel（首次需先开通免费套餐）
  3. 创建时选 Docker 方式，页面会展示 cloudflared tunnel run --token <TOKEN>，其中 <TOKEN> 就是 Install Token，填入设置页
  4. 给 Tunnel 添加 Public Hostname：子域如 app、域名选你的、Service 填 http://NAS_IP:19999
  5. 保存后从外网访问 https://app.你的域名.com 即可

② Tailscale（P2P 组网直连，不限速）

  1. 注册：https://login.tailscale.com/（免费，可用 Google/GitHub 登录）
  2. 生成一次性密钥：Admin → Settings → Keys → Generate auth key → 复制，填入 Auth Key
  3. 其他设备装 Tailscale 登录同一账号即组网，获得 100.x IP 直连

③ ZeroTier（虚拟局域网，免费 50 节点）

  1. 注册：https://my.zerotier.com/
  2. Create A Network，进入网络详情页，顶部 16 位十六进制 Network ID 填入设置页
  3. 其他设备加入同一网络，并在网络详情页把本机节点 Auth 批准

④ openP2P（开源 P2P 打洞，免服务器）

  1. 官网：https://openp2p.cn/，控制台：https://console.openp2p.cn/
  2. 注册登录后，节点信息页展示 节点 ID（填设置页 Peer ID）与 Token（纯数字 App Key）。openP2P 要求 Token 必须为纯数字，非数字会保存但引擎不会启动。

常见问题

问题处理
面板打不开确认端口 19999 未被占用；自定义端口用 NAS_IP:端口 访问
Cloudflare 连不上免费版边缘节点在国内可能不稳定，可切 Tailscale/ZeroTier 兜底
引擎一直「未启用」确认勾选开关且 Token 已填；查看数据目录 info.log
Token 看不到完整值属正常打码保护，重新保存即覆盖

更多说明见随包《使用教程》。配置持久化于应用数据目录 tunnel.env，日志见 info.log。
