# 穿透管家（fn-tunnel-hub）详细使用教程 v2.1.6

一个应用集成 4 大免费内网穿透方案，**免公网 IP、免 FRP 服务器**，NAS 主动出站建连，支持绑定自己的域名。
本版本为**原生模式**：Cloudflare Tunnel / Tailscale / ZeroTier / openP2P 四引擎二进制全部内置，**无需 Docker**，按设备架构自动加载 `amd64` 或 `arm64` 二进制。

---

## 一、安装包信息

| 项目 | 值 |
|---|---|
| 包名 | `output/fn-tunnel-hub-fpk-v2.1.6.fpk`（约 112 MB） |
| 应用版本 | v2.1.6 |
| 面板默认端口 | **19999** |
| 支持平台 | x86_64 + arm64 |
| 最低系统 | fnOS 1.1.8 |

### 安装步骤

1. 飞牛桌面 → **应用中心** → 右上角 **设置** → **手动安装应用**
2. 选择 `fn-tunnel-hub-fpk-v2.1.6.fpk`
3. 安装向导极简两步：
   - **面板端口**：默认 `19999`，如需自定义在这里改
   - **自动更新**：是否启用
4. 完成安装。Token 等引擎配置**不需要在向导填**，安装后进主页「设置」页配置

> 若安装向导里自定义了面板端口（如 28888），应用会额外在 19999 起一个兼容监听，保证飞牛桌面图标始终能打开面板。

## 二、面板使用

安装完成后，桌面图标或浏览器打开 `http://NAS_IP:19999` 进入「穿透管家」面板。面板分两个 Tab：

### 1. 状态页

- 四个引擎一张卡片，实时显示运行状态（`运行中 / 未启用 / 未运行`）
- 卡片数据由 `status.json` 提供，每次保存设置或应用启动时刷新

### 2. 设置页（配置入口）

在这里填写各引擎的 Token / 域名 / 节点 ID，勾选要启用的引擎，点 **保存** 即生效：

- 保存后内容持久化到应用数据目录 `tunnel.env`
- 配置接口会调用主程序 `apply_config` **自动重启所有引擎**（面板不中断）
- 敏感字段（Token）保存后回显自动打码（如 `eyJ...****`），只显示后 4 位

| 字段 | 说明 |
|---|---|
| CF Token | Cloudflare Tunnel 的安装 Token |
| CF Hostname | 你要绑定的公网域名 |
| TS AuthKey | Tailscale 一次性认证密钥 |
| TS Hostname | 本机在 Tailscale 网络中的主机名（默认 `fnos-nas`） |
| ZT Network ID | ZeroTier 网络 ID（16 位十六进制） |
| P2P Peer ID | openP2P 节点 ID |
| P2P Token | openP2P 节点 Token |
| 引擎开关 | CF / TS / ZT / P2P 四个独立开关 |
| 面板端口 | 下次重启生效 |

## 三、四引擎配置指引（凭据获取）

> 四引擎均免费。Token 各自去官方控制台获取后填入设置页。

### A. Cloudflare Tunnel（推荐：外网直接访问，可绑域名，自动 HTTPS）

1. 注册 Cloudflare 并托管你的域名：`https://dash.cloudflare.com/`
2. 进入 Zero Trust：`https://one.dash.cloudflare.com/` → **Networks → Tunnels → Create a tunnel**
   - 首次使用需先开通免费套餐，得到你的团队域名
3. 部署方式选 **Docker**（示例），页面会给出 `cloudflared tunnel run --token <TOKEN>`，其中 `<TOKEN>` 即 **CF Token**
4. 给 Tunnel 添加 **Public Hostname**：Tunnels → 点该 Tunnel → **Public Hostname → Add**
   - 子域填 `app`，域名选你托管的域名，Service 填 `http://<NAS_IP>:<面板端口>`（如 `http://192.168.1.10:19999`）
5. 保存后外网访问 `https://app.你的域名.com` 即可直达你的内网服务页

### B. Tailscale（P2P 组网直连，不限速）

1. 注册：`https://login.tailscale.com/`（免费，可用 Google/GitHub 登录）
2. 生成一次性密钥：`https://login.tailscale.com/admin/settings/keys` → **Generate auth key** → 复制
3. 填入面板设置页 **TS AuthKey**，保存后自动拉起 `tailscaled` 并 `tailscale up`
4. 其他设备装 Tailscale 客户端登录同账号即组网，获得 `100.x` 内网 IP 直连
5. 需要对外暴露公网：官网该节点 **Edit route settings → Enable Funnel**，或在 ACL 中放行后用 `tailscale funnel` 绑定

### C. ZeroTier（虚拟局域网，免费 50 节点）

1. 注册：`https://my.zerotier.com/`
2. **Create A Network**，进入网络详情页
3. 顶部 **Network ID**（16 位 hex，如 `a1b2c3d4e5f6f7f8`）填入 **ZT Network ID**
4. 其他设备装 ZeroTier 客户端加入同一网络；并在网络详情页把本机节点 **Auth 批准**，节点才获得 `10.x` IP

### D. openP2P（开源 P2P 打洞，无需服务器）

1. 官网：`https://openp2p.cn/`，控制台：`https://console.openp2p.cn/`
2. 注册登录后，节点信息页展示 **节点 ID（Peer ID）** 与 **Token**
3. 分别填入 **P2P Peer ID** / **P2P Token**，保存后自动打洞
4. 按 openP2P 文档配置端口映射即可公网访问

## 四、常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 面板打不开 | 确认端口 19999 未被占用；自定义端口时用 `NAS_IP:自定义端口` 访问 |
| Cloudflare 连接失败 | 免费版边缘节点在国内可能不稳定，属正常；可切 Tailscale/ZeroTier 兜底 |
| 改了端口不生效 | 端口需**重启应用**后生效；面板不变端口只改引擎配置会立即应用 |
| 引擎状态一直「未运行」 | 保存前确认已勾选对应引擎开关且 Token 已填；查看应用数据目录 `info.log` |
| Token 保存后看不到完整值 | 属正常打码保护，避免明文泄露；重新保存会覆盖原值 |

## 六、开发与打包（可选）

```bash
# 源码目录结构（原生模式）
fn-tunnel-hub/
├── manifest          # version=2.1.6, service_port=19999
├── cmd/main          # 生命周期入口（start/stop/status/apply_config）
├── cmd/*_init|*_callback|updater.sh   # fnOS 安装/卸载/升级钩子
├── wizard/install    # 向导：仅面板端口 + 自动更新
└── app/
    ├── bin/amd64、bin/arm64   # 四引擎二进制（按架构自动加载）
    └── www/                   # index.html（状态页+设置页）+ config.cgi

# 用官方 fnpack 打包
fnpack build --directory fn-tunnel-hub
# 产出 fn-tunnel-hub.fpk
```
